`totem doctor`'s Secret Scan no longer reads an English hyphenation that ends in `sk-` as a leaked key. The two OpenAI-shaped patterns (`sk-…`, `sk-ant-…`) now require the token to start at `sk-`: an ASCII letter before it makes it the tail of a word, so `ask-the-registered-lead-first…`, `Ask-…`, `task-…`, `risk-…` and `desk-…` runs of twenty or more word characters pass, while a key after a quote, a bracket, an equals sign, an underscore, a digit, a non-ASCII letter or the start of a line is still caught. The one shape this lets through is a key glued to the letter that ends an escape or a percent-encoding (a literal backslash-n before it, a JSON unicode escape, a percent-encoded equals sign), which the old pattern caught. The scan runs over `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.cursorrules` and `.totem/lessons/*.md`, and on the strict tier or an agent seat the pre-push hook runs it through `totem doctor --strict`, so a lessons corpus written in English no longer refuses its own push (mmnto-ai/totem#3131).
