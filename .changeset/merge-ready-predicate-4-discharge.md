The merge-ready gate's predicate 4 (`high-severity-inline`) now reads the DISPOSITION PATH (mmnto-ai/totem#2861). A HIGH/Major bot inline whose `comment.commit.oid` is the head commit no longer counts as "still applying" when its thread is RESOLVED and the `totem resolve-threads` evidence rule holds on the same read: a non-bot reply after the root inside the thread, or a non-bot PR-level comment created strictly after the root. A resolved HIGH with no such evidence on record — a bare resolve — still applies, and the deny reason now says so; an unresolved HIGH still denies at predicate 2, so the resolve remains a required step of the path rather than an optional one. The read is one GraphQL document as before: every thread comment now carries `createdAt`, `author { __typename }` and the window's `pageInfo`, and the PR-level `comments` connection is paginated in full beside the other three — each held to the same strict bar (a missing connection, `pageInfo`, `createdAt` or `__typename` is an unreadable page, named, never "no evidence"). A resolved HIGH whose evidence the read could not settle (more replies than the ten-comment window and none of the read ones a human's, no PR-level comment after the root either) is the UNEVALUABLE class, named on stderr, at the same precedence as the null-commit arm — never a silent deny and never a discharge. Provenance carries a new `dischargedHigh` count beside `highInline` (which now counts what still applies after the discharge), and a discharge prints one audit line on stderr naming the count. Disclosed, as resolve-threads discloses it: the PR-level arm is not keyed to the round-disposition comment, so an operator's trigger comment that post-dates a root is evidence too — which is why the disposition is posted BEFORE the resolve. The fixture README, the four PR captures (re-captured with the new query, plus mmnto-ai/totem#2871 as the real discharge specimen) and nine synthetic rows carry the shapes. (The packages share one fixed changeset group, so every `@mmnto/*` package takes the same minor bump.)
