The merge-ready gate's predicate 4 (`high-severity-inline`) now reads the DISPOSITION PATH (mmnto-ai/totem#2861). A HIGH/Major bot inline whose `comment.commit.oid` is the head commit no longer counts as "still applying" when its thread is RESOLVED and a disposition is on record: a non-bot reply after the root inside the thread, or a non-bot PR-level comment created strictly after the root that carries the review-reply skill's `local-lane:` line at line start — the line a round disposition posted through `/review-reply` usually ends with (fenced or not) and that no trigger comment, gate-read note or merge note carried on any of the fourteen calibration rows. A resolved HIGH with no such line after its root — a bare resolve, however much human chatter follows it, or a disposition posted without the line — still applies at every tier, and the deny reason names the line it looked for, ahead of the quoted finding so the cause survives the bound on `provenance.matched`; an unresolved HIGH still denies at predicate 2, so the resolve remains a required step of the path. Disclosed, not closed: the PR-level arm is keyed to the ROUND, not the thread — no per-thread reference exists in a round disposition today — so a HIGH rooted before a disposition that did not address it is discharged if someone then resolves it by hand; the thread-level linkage that would close that class is the operator's ruling on the issue. The read is one GraphQL document as before: every thread comment now carries `createdAt`, `author { __typename }` and the window's `pageInfo`, and the PR-level `comments` connection is paginated in full beside the other three with `author`, `body` and `createdAt` per node — each held to the same strict bar (a missing connection, `pageInfo`, `body`, `createdAt` or `__typename` is an unreadable page, named, never "no evidence"). A thread with more comments than the ten-comment window is judged on what was read: evidence found inside the window or at PR level discharges it, and a window with none is a fact-side deny at every tier whose reason names the window — never the unevaluable class. Provenance carries `dischargedHigh` and `dischargedBy` (in-thread reply vs PR-level disposition) beside `highInline`, which now counts what still applies after the discharge, and a discharge prints one audit line on stderr naming the count and the arms. The `totem resolve-threads` evidence rule this otherwise mirrors is deliberately weaker (the verb decides whether a thread MAY be resolved and accepts any post-dating non-bot comment, a trigger included), so a thread the verb resolved on the strength of a trigger stays applying here until a disposition with the line is posted. The fixture README, the four PR captures (re-captured with the final query, plus mmnto-ai/totem#2871 as the real discharge specimen) and ten synthetic rows carry the shapes, the negative control in the field shape a falsification leg constructed. (The packages share one fixed changeset group, so every `@mmnto/*` package takes the same minor bump.)
