When the prefer-local re-exec delegates to a workspace build, it now reports how current that build looks (mmnto-ai/totem#2934). A workspace build is a checkout that carries `packages/cli` named `@mmnto/cli`, which is this repository. The delegation banner names the instant the delegated `dist` was built, as ` (built <ISO>)` after the version. When a file under `packages/cli/src` or `packages/core/src` has a newer modification time than that package's `dist/index.js`, one more stderr line says the build may be stale, names both instants, and suggests `pnpm build --force` if the source changed. A cached turbo build does not re-stamp `dist`. The line names the workspace root, because the forced build must run there: inside a package directory, `pnpm build --force` passes `--force` to that package's `tsc` and fails. The CLI still delegates: the line is a sensor, and argv, environment and exit code are unchanged.

A direct run of the workspace build (`node packages/cli/dist/index.js <verb>`) prints nothing new and does not read the source tree. The pinned tier that consumers use (`node_modules/@mmnto/cli`) is unchanged byte for byte, and no modification time is read there. `TOTEM_NO_REEXEC=1` still turns the whole re-exec off. If the source tree cannot be read, the banner drops the build instant and no stale line prints. Under `TOTEM_DEBUG=1`, one `[totem] freshness probe failed: <message>` line names the failure, and delegation still proceeds.

Limits: the check compares modification times only. It does not see a deleted source file or a rename that keeps its modification time, and it skips symlinked sources. A touched or reverted file (same content, newer modification time) reads as newer. Every file under `src` counts, including tests and fixtures that are not compiled into `dist`, so editing a test trips the line although the build is current. A source file stamped in the future keeps the line printing after a forced build until the clock passes that stamp. That is why the line says "may be stale" and "if the source changed".
