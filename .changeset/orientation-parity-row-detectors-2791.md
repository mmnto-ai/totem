**`gh-issue-label-canon`.** The canon is derived at run time from `scripts/sync-labels.ps1`'s `gh label edit` calls — never a mirrored table (Tenet 20): on this repository the local checkout is read, elsewhere the script is fetched from `mmnto-ai/totem`'s default branch and the line discloses which (`canon: local checkout …` or `canon: mmnto-ai/totem:scripts/sync-labels.ps1@<blob sha>`). Each roster repo's labels are read through paginated `GET /repos/<slug>/labels` (a list past the page cap degrades the whole surface, never an undercount) and judged: `pass` when every canonical name is present with its canonical colour and description and nothing outside the canon sits in a canonical namespace; `warn` naming the missing, the redefined and the out-of-set names; extra labels outside the namespaces (`disposition:*`, `routine:*`, bare words) and a retired name still present are reported, never flagged. The namespace tokens are derived from the canonical names, the space kept on the colon tokens, so `type:audit` is a bare word and `scope: docs` is out-of-set.

**`gh-project-vocabulary`.** The canonical option sets come from the manifest row: a structured `expected-option-sets: { Status: [...], Priority: [...] }` field when the row carries one (the field's contract, ruled by strategy 2026-09-05 and landing in the 0.1.44 doctrine batch — the core manifest loader admits it as an optional per-row field, mis-shaped → absent on that row, never a dark manifest), else the row's `expected-value-or-derivation` prose parsed with the pinned interim grammar (`Field = a | b; …`). Either way a doctrine bump moves the canon with no code change, a text the grammar cannot read renders `unknown`, never a hardcoded pass, and the line names which canon it read. The current repo's bound project (`orient.projectNumber`) is read once through a new injectable GraphQL seam (`gh api graphql`, read-only) and its single-select fields compared as SETS, order-insensitive: `pass` when both governed sets equal the canon (extra fields and a different option order are reported, not flagged); `warn` naming a missing or extra option, or an absent governed field; a repo with no binding, and every sibling in `orient.parityProbeRepos` (its config is not a network surface), render honest-absent `skip`.
