New gate event `action-policy`: a consumer-authored `.totem/action-policy.json` (`version: 1`, optional `environments[]` of `{ name, branches }`, and `rows[]` of `{ id, action_kind, scope: { paths?, commands? }, environment?, disposition, reason? }` over eight action kinds: `code_edit`, `secret_read`, `db_migration`, `db_data_write`, `deploy_config_change`, `deploy_trigger`, `scheduled_job_change`, `index_rebuild`) classifies an agent's edits and shell commands, and `totem gate install action-policy` installs it as one PreToolUse entry under the new `Write|Edit|Bash|PowerShell` matcher. The wrapper projects a Write or Edit to `{ tool, path }` and a Bash or PowerShell call to `{ tool, command, platform }`, and passes any other tool or an empty value through without spawning. Path rows use the path-classifier glob dialect against the repo-relative path (a path outside the repository is never governed); command rows are token-prefix patterns, each token a glob in the same dialect, matched per statement after the transport shield's shell split, so `pnpm db:migrate:prod` matches `cd apps/api && pnpm db:migrate:prod --force` and not `pnpm db:migrate:prod-report`. A row naming an environment applies when the current branch matches that environment's branch globs; the branch is read only when such a row matched, and an unreadable branch is `deny` at the strict tier and `warn` at the pilot tier, never an allow. The most severe matching row wins and the verdict cites its id, kind and what matched; a `display` row reports through the warn arm and never blocks. `TOTEM_ACTION_POLICY_OVERRIDE=<row-id>[,<row-id>]` turns a named row's `deny` into `allow` with one stderr line and `overriddenBy` in the provenance. No file allows everything; a corrupt or schema-invalid file fails closed. `totem orient` gains an ACTION POLICY section (only when the file exists) listing the rows and the governed paths among the branch diff and the working tree, also in `--json` as `actionPolicy` and as one counts line in the session block, and `totem doctor` gains a sensor-only Action policy row that warns on a corrupt file and never gates. The core git adapter gains `getGitStatusPorcelainRaw`, a `status --porcelain -z` read that throws on a git failure so a failed read never looks like a clean tree. Disclosed limit: a governed program invoked by path, inside `sh -c`, from a script the agent wrote or under another name matches no command row. Part of mmnto-ai/totem#3106.
