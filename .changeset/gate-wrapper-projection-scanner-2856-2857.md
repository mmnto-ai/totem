fix(gates): the merge-ready gate wrapper now judges the projection shapes that bypassed it, bounds its whole run by one budget, and carries core's heredoc scanner verbatim (mmnto-ai/totem#2856, mmnto-ai/totem#2857). Under the pilot tier each of these was one lost advisory read; under the strict tier each was a bypass, so both issues were the strict install's precondition. WHAT IS JUDGED NOW: the executable may be spelled `gh`, `gh.exe`, or either behind a path (the basename after the last `/` or `\`, with a case-insensitive `.exe`); a CLOSED table of transparent wrapper programs is stripped with its option grammar before the anchor is read (`sudo`, `env`, `timeout`, `nice`, `nohup`, `command`, `exec`, `time` — which options take a separate operand, how many positionals the word itself eats, whether `--` ends its options), with the assignment strip re-running after each so `env -u X A=1 gh pr merge 5` and `sudo -u root timeout 30 gh pr merge 5` both resolve; `eval` re-tokenizes its operand once (depth 1); a leading redirection is skipped with its file token; and a backtick becomes a segment separator, so the operand of a backtick substitution is a segment of its own (the backtick rides on as a token, so a merge whose TARGET is a substitution still reports `unresolvedTarget` rather than falling back to the current branch). THE STRIP TABLE, CORRECTED BY THE FALSIFICATION ROUND: `sudo`'s describe-only options (`-l`/`--list`, `-v`/`--validate`, `-V`/`--version`, `-K`/`--remove-timestamp`) run nothing, so a merge behind one is no longer projected — that was a FALSE DENY; every long option that takes a SEPARATE operand joins its word's operand list (`sudo --user|--group|--prompt|--chdir|--chroot|--host|--role|--type|--other-user|--command-timeout`, `env --unset|--chdir`, `timeout --kill-after|--signal`, `nice --adjustment`), without which the operand itself read as the program and the merge behind it went unjudged; and `time` is read as bash's RESERVED WORD (`time [-p] [--] pipeline`), where any `-` token that is not `-p` means the shell runs nothing — GNU `/usr/bin/time`'s `-o`/`-f` grammar belonged to a different program. THE REDIRECTIONS: one strip over the WHOLE segment now runs ahead of the wrapper strip and the anchor test, so a trailing redirection never rides into argv (`gh pr merge --squash > merge.log` reached the engine as a pull request on branch `>`, a deny with a reason no one wrote) and a redirection between the executable and its verb no longer breaks the anchor; an operator alone takes the file token with it, a fused one (`>out.txt`, `2>/dev/null`, `<<<bar`, `2<>file`) goes alone, and a `<<EOF` head drops harmlessly because the scanner blanked its body first. THE BUDGET: the wrapper's deadline is now set at its entry, before stdin is read and before any projection, so the projection's git reads are bounded by what is left of it (10 s ceiling, 250 ms floor, no spawn at all once it is spent) instead of running up to three 10-second reads ahead of a deadline that did not yet exist — where a hung git reached the HOST's hook timeout and a killed hook's exit code is never applied, a fail-open on a fail-closed gate. A spent budget writes `[totem gate-wrapper] the <n> ms budget was spent before gate "<event>" could be evaluated …` and exits 2 at every tier, without spawning the CLI. The READ of the envelope is inside the budget too: a timer armed at the entry writes `[totem gate-wrapper] the <n> ms budget was spent before the envelope arrived on stdin — blocking (fail-closed).` and exits 2 if stdin never closes, where before the hook waited unbounded until the host killed it — a killed hook's exit code is never applied. MINOR: a new hook argument `--budget-ms <n>`, in either spelling (`--budget-ms 1500` or `--budget-ms=1500`, last-wins on a repeat), which the installed settings.json line never passes and which can only LOWER the budget (a value below 1000 reads as 1000; above 30000 or unparseable reads as the 30000 default). THE SCANNER: the wrapper's `blankHeredocBodies` was a hand copy of core's `findHeredocs` that had diverged in the fail-open direction — no paren-boundary arms (so a `#` after `(` or after an operator `)` was text and a `<<word` inside it opened a body), a narrower bare-delimiter class (so `<<E:F` read as the prefix `E` and the terminator line never matched), and a double-quote backslash that escaped any next character where core escapes only `$`, backtick, `"`, `\` and newline. Each of those blanked a `gh pr merge` on a later line. It is now a verbatim port of core's walk and its three tables, returning core's spans minus the unused `body`, with the blanker replacing a body with spaces so every offset is preserved; both sites carry a `sync-anchor` comment and an executable parity test holds the two span-for-span equal over the suite's whole command corpus and a seeded 3 000-string fuzz corpus in both bash and PowerShell modes. Core is unchanged apart from that one comment line. The committed `.claude/hooks/gate-wrapper.cjs` is re-scaffolded from the new template. Disclosed and locked as rows, unchanged in the safe direction: a variable executable (`$GH`), an unquoted win32 path (this walk reads POSIX quoting for both tools), `timeout` with no duration, a program not on the closed table (`npx`, `xargs`, `bash -c`), a table word spelled by PATH (`/usr/bin/time -f x gh pr merge 5` — a program with its own option grammar, not the reserved word), `env -S '<cmd>'` / `env --split-string='<cmd>'` (the option's operand IS the command, split again under env's own rules), `eval` nested deeper than one level, a SUBSTITUTION INSIDE DOUBLE QUOTES (``echo "`gh pr merge 5`"``, `echo "$(gh pr merge 5)"` — bash executes both, the tokenizer's quote arm swallows the string whole, so the merge runs unjudged: a fail-open filed as mmnto-ai/totem#2893), and the redirection operators whose own separator ends the segment first (`>|`, `2>&1`, `>& file`, `<& 3`, `exec 3>&1 …` — `|` and `&` end the token before the operator is whole; `&>` splits the same way but leaves a readable `>` at the front of the next segment, so that one IS read). Disclosed FALSE FIRE, the deny direction on contrived text: in PowerShell mode a double-quoted string whose backtick escapes a quote (``Write-Output "a `"; gh pr merge 5`"b"``) is one string to PowerShell and merges nothing, but this walk reads POSIX quoting for both tools and judges the merge inside it.
