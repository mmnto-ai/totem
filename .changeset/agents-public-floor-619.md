`totem init` now scaffolds a public `AGENTS.md` floor. When a repository has no `AGENTS.md`, init writes one: a title carrying the project name, a managed span between `<!-- totem:agents-floor:start -->` and `<!-- totem:agents-floor:end -->`, and a stub for the repository's own conventions. The span is the product-valid instruction set any consumer gets — session start (`totem status`, `totem search`, `search_knowledge`, `totem lint` before the first push, `totem orient` on a cold start), the working rules (formatter, lint as the enforcement floor, review as the advisory lane, lesson extraction after merge, never bypass a gate without a ticket, the context re-check after long edits, controller-not-implementer), the review-bot conduct, and the installed skills. It names no vendor, no private repository, no deployment and no doctrine tag. Every later `totem init` refreshes exactly the bytes from the start marker through the end marker and leaves every other byte alone; a repository whose `AGENTS.md` carries no markers is never rewritten and is told once, dimly, how to adopt the span. `totem eject` removes the span (and the file, when the span was all it held), keeping the repository's content around it byte-exact. (The packages share one fixed changeset group, so every `@mmnto/*` package takes the same minor bump.)

The template is held sterile by a test in the package that ships it (`agents-floor-sterility.test.ts`): no private repository path, deployment name, operator fingerprint, doctrine tag, agent identifier, vendor name or unqualified issue reference in the span or the rendered scaffold. The same test holds this repository's own committed `AGENTS.md` to carrying the span byte-identically — the sterile floor is the init scaffold, which is the product test the sterilization issue named — and holds every public agent-instruction surface here (the floor, the two redirects, the Junie twin, the three `.claude/docs` pages) to the same lexicon plus resolvable relative links, with one declared exception: the `totem:agent-bus` marker line, whose move into a committed config file is mmnto-ai/totem#2866. `tools/public-refs-resolve.mjs` is the network half of that acceptance test: it probes every URL, qualified issue ref and qualified path a file carries without a token and reports the ones a public reader cannot follow.

This repository's `AGENTS.md` is the first render: rewritten line by line to the T0 floor, with the team-only content re-homed in the private overlay the doctrine pin distributes and the dead pointers cured (`AI_PROMPT_BLOCK` lives in `init-templates.ts`, not `init.ts`; `/signon` joins the skills list). The redirects, the Junie twin, the contributing and agent-workflow docs and the Gemini styleguide's deployment and operator lines are swept under the same rubric. Not in this cut: the distributed skills' managed text and the styleguide's doctrine links, which carry private references by design of their audience and are inventoried in a follow-up issue.
