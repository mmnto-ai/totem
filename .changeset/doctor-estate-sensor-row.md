`totem doctor` gains the worktree-estate sensor (mmnto-ai/totem#2580 slice 1): `totem doctor --estate` enumerates the repos in the user-level registry, classifies each repo's linked worktrees from local git evidence alone, and sweeps the derived roots (the parents of registered repos and their worktrees, extendable with the repeatable `--root <dir>`) for unregistered worktree-shaped residue. Read-only by construction — the only git verbs invoked are `worktree list --porcelain`, `status --porcelain`, `merge-base --is-ancestor`, `log -1`, and `rev-parse` — and report-only: it exits 0 whatever it finds, because removal verbs are a later slice.

The classifier is deliberately conservative about what it will claim. Dirty tree is `active`; clean and ancestry-merged into the default branch is `stale`; clean and NOT ancestry-merged is `indeterminate`, never `stale` — a squash-merged branch leaves no ancestry edge, so from local git it is indistinguishable from an unmerged one, and this sensor has no merged-facts source to settle it (that arrives with the status-lane snapshot extension). Husk candidates require positive, typed evidence (`dangling-gitdir-pointer`, `residue-shape`, `deregistered-intact`); a directory with a real `.git` directory is never reported, a path that appears in any repo's worktree list is never a husk candidate (case-folded on win32, where git and Node can disagree on drive-letter case), and every failed probe surfaces as an `unscannable` row rather than silently shrinking the scan.

`--estate --json` emits the scan as a diffable artifact on stdout (kebab-case keys, presence-only optional keys, no CLI envelope), with `estate-schema-version: 1` as the compatibility contract for downstream consumers; the artifact replaces the human render wholesale, and an empty or unreadable registry still yields a valid degenerate artifact carrying `registry-status: empty`. Plain `totem doctor` gains a matching ambient `Estate` row: a named SKIP when nothing is registered, a quiet PASS when the estate is clean, and a WARN naming the counts and pointing at `--estate` when husks or stale worktrees exist — never a failure, since this row is a sensor and not a gate. `@mmnto/totem` exports the underlying `scanEstate` plus the first reusable `parseWorktreeListPorcelain` parser.
