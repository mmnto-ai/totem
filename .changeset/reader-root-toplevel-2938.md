The mail reader verbs resolve the repository the way the send does, and refuse to read or write anywhere else (mmnto-ai/totem#2938, mmnto-ai/totem#2946, mmnto-ai/totem#2968). Core's `findTotemRepoRootSync` now prefers the nearest `.git` toplevel over a nearer `.totem/`: a `.totem/` a tool minted under a subdirectory (`packages/cli/.totem/temp`, a committed fixture's `.totem`, a phantom `apps/<x>/.totem/orchestration/`) no longer captures a verb run beneath it — a poll from `<repo>/packages/cli` read an empty workspace as clean and a mark landed in a store no poll drains. A `.totem`-only tree with no `.git` at any height still resolves to its nearest `.totem/`, so bare fixtures keep working; every consumer of `resolveTotemRepoRootSync` (`seat`, the doctor's seat-identity row, `deriveSeat`) inherits the preference. Two new core exports classify what the walk landed on — `classifyTotemRepoRootSync` (`toplevel`, `worktree` with the resident checkout named from the `.git` file's `gitdir:` pointer, or `none`) and `mainCheckoutFromGitFileSync` — and a new error code, `REPO_ROOT_REFUSED`, exits `2` at the CLI (the NOT-DERIVED family). The poll, `mail mark`, `ecl-gc` and its compaction now refuse the `none` class (outside any repository the old fallback used the start itself: "inbox clean" over nothing, or a phantom `processed/` tree minted there) and the `worktree` class (a worktree hosts no seat and no poll enumerates it; a mark from one mints a store the resident never drains, so the source stays unread forever) before anything is read or written, each with one line naming the resident checkout to run from. `pollMail` throws for this one case; its never-throws contract for filesystem failures otherwise stands. `totem doctor` gains the gate-exempt "Stray Markers" row, which lists every `.totem/` under the repository that is not its root marker, with the remedy. Minor for cli and core: two new core exports, a new error code, a changed resolution rule for every walker consumer, and a refusal where three verbs previously read an empty workspace as clean or minted a phantom store. No skill text changes.
