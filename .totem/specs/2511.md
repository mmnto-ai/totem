# Spec 2511 — seat-lifecycle verbs: `totem seat add | suspend | remove` (+ `list`)

> Provenance: the machine-generated spec for this issue was replaced by hand 2026-08-12 (totem-claude).
> The generated draft invented paths that do not exist (`packages/core/src/config/schema.ts`,
> `packages/cli/test/`, `config-mutator.ts`) and proposed a breaking `host_agents` object schema;
> everything below is verified against primaries at `main` @ `1aac848d` (file:line cites) plus the
> issue charter and the 2026-08-01 status-claude spec-time deposit.

### Problem statement

Seat lifecycle events (birth, suspension, retirement) currently exist only as operator words and
hand-edits. There is no derivable seat-state: a suspended seat stays in every poll union and every
broadcast required-set forever (a suspended-but-dir-present seat pins every broadcast open — the
denominator failure measured in `totem-status:orchestration.go:184-189`), birth-time wiring is
folklore (poll asymmetry, cohort-roles §6.6), and identity binding (§1.4 agy incident) has no sensed
surface. Charter: a vendor-neutral totem CLI mechanism under the ADR-094 entity-namespace grammar.

### Architectural context (verified)

- **Seat existence is dir-derived** (`packages/core/src/orchestration-resolver.ts`): the #2141
  dirs-union invariant self-registers a seat on first write; `readSeatDirs` (190–203, currently
  module-private) enumerates; `resolveSelfAgents` (351–426) resolves env > config > dirs∪map.
- **`.totem/orchestration/config.json` is `{ host_agents?: string[] }` with REPLACE semantics**
  (271–275); this repo carries none (strategy does). The resolver explicitly rules
  *"config-exclusion is not a sanctioned decommission mechanism"* and warns loudly on a
  present-but-omitted seat dir (376–393) — so suspension must NOT be modeled by config surgery.
- **The orchestration tree is gitignored** (`.gitignore:71`): seat state is machine-local, matching
  ECL's machine-local design. Lifecycle markers inherit that scope deliberately.
- **Broadcast denominators**: `pollMail` requires every resolved self seat's mark for a
  broadcast-named file (`mail.ts` — `required = max(selfSeatCount, 1)`, #2412); the cohort-side
  twin is `orchestration.go:2373-2405`. `suspended` must leave the *denominator*, not just the poll.
- **Axis ruling (this spec's one-sentence obligation, status-claude 2026-08-01 §1):** lifecycle
  (`active | suspended | retired`) is DECLARED — operator-driven, durable, owned here; session state
  (`LIVE/IDLE/FAULTED`) is DERIVED by the totem-status#127 projection, which CONSUMES lifecycle;
  `suspended` is not a session state and no session state is ever written into a lifecycle marker.
- **Obligation edges are not discharged by lifecycle transitions** — explicit disposition with
  provenance is totem-status#127's contract; the verbs reference it, never re-derive it. A retired
  seat's outbox retention is #2518's lane (this spec never deletes).
- **ADR-115: in-boundary (ECL/mail)** — the diff touches `pollMail` runtime behavior. The PR body
  carries the verdict line; a degraded-path induced-failure test follows the three-assertion E4
  pack contract (`mail-degraded-e4.test.ts:1-11`): accounting fires, backstop holds, never silent
  narrowing.

## Implementation Design

### Scope

Adds `totem seat add | suspend | remove | list`: per-seat declared lifecycle markers, a derivable
seat-state read surface, lifecycle-aware broadcast denominators in `pollMail`, an emitted (never
auto-applied) birth/retirement propagation checklist, and a doctor-tier identity-binding sense.
It will NOT: delete or prune any seat data (retention = #2518), auto-edit vendor hook files or any
foreign surface (`agentHomeMap`, `eclCohortRepos` [#611-frozen], signoff seat tables — emitted as
checklist lines only), derive session state (totem-status#127), add a parity-manifest row (the
manifest is strategy-owned — checklist line for the strategy lane), create a `config.json` where
none exists, or touch `COHORT_AGENT_MAP` (demoted bootstrap fallback).

### Data model deltas

| New thing | Holds | Written by | Read by | Invariants |
| --- | --- | --- | --- | --- |
| `SeatLifecycleState` (core enum) | `'active' \| 'suspended' \| 'retired'` | — | all consumers | closed set; session states structurally unrepresentable |
| `SeatLifecycleMarkerSchema` (core, `.strict()`, `schemaVersion: 1`) | `{ schemaVersion, state, since (ISO-8601), by?, reason? }` | `seat add/suspend/remove` via `writeFileAtomicSync` | `deriveSeatStatuses`, `pollMail`, doctor | `by` is the env-resolved seat if `TOTEM_SELF_AGENT` is set, else **omitted** (stamped absence — never fabricated, the #2625 MB-2 rule) |
| Marker file `.totem/orchestration/<seat>/lifecycle.json` | one marker | the verbs only | same | **absent ⇒ `active`** (every existing seat unaffected; markerless trees behave bit-identically) |
| `deriveSeatStatuses(repoRoot)` (core) | derived `{ seat, state, since?, source: 'marker' \| 'default-active', marker? }[]` | — | `seat list`, doctor — NOT `pollMail`, which calls `readSeatLifecycle` per RESOLVED seat so the denominator filter can never route through `readSeatDirs`' silent-`[]` degradation (amended at build, slice-3 finding) | derives from `readSeatDirs` + markers at read time; never cached/persisted (Tenet 20) |
| `readSeatDirs` export | (existing fn) | — | core barrel consumers | widened export (`index.ts:911-916`) — the alternative is a **fourth** private re-implementation (`mail.ts:457` is the third) |

No reserved keys, no sentinels. `resolveSelfAgents` / `SelfAgentResolution` are **unchanged** —
resolution answers "who exists / who am I" and stays lifecycle-blind; lifecycle filters downstream
consumers (denominators, annotations), never existence. `host_agents` stays `string[]`.

### State lifecycle

- **Scope:** persistent, per-repo, per-machine (gitignored tree — deliberate, matches ECL).
- **Lifetime:** marker created by `seat add` (or first `suspend`/`remove` on a markerless legacy
  seat); mutated only by the verbs (full-file atomic replace, PID-temp + rename); never destroyed
  by this feature (a `retired` marker is the durable tombstone; deletion is #2518's call).
- **Ownership:** `packages/core/src/seat-lifecycle.ts` owns all reads/writes; the CLI command layer
  never touches the file directly.
- **Cross-boundary note:** `pollMail` (per-invocation) consumes persistent markers — the classic
  seam. The marker is read fresh on every poll (no caching), so a transition is visible to the next
  poll with no invalidation step.

### Failure modes

| Failure | Category | Agent-facing surface | Recovery |
| --- | --- | --- | --- |
| Marker unparseable/corrupt at read (poll, list, doctor) | runtime | **warning + treat seat as `active`** — fail-open on visibility: a corrupt marker must never shrink a broadcast denominator (wrongly closing an obligation) nor hide held mail | fix or delete the marker; next read heals |
| Marker write fails (EACCES, disk) | runtime | hard `TotemError`, no partial transition | re-run; atomic write means old-state-or-new-state |
| `seat add` on existing seat (dir or marker) | usage | hard error naming current state; suspended seats get the `--reactivate` hint | `--reactivate` or pick a new id |
| `seat add`: dirs created, then `host_agents` rewrite fails (only in repos that carry the file) | runtime | hard error naming completed vs failed steps | re-run — dir creation and config merge are both idempotent |
| `host_agents` rewrite drops passthrough keys or existing seats | (designed out) | — | merge = read full JSON, append seat, write back complete object; contract test pins round-trip |
| `suspend`/`remove` on unknown seat | usage | hard error listing known seats | — |
| All self seats suspended → broadcast denominator 0 | runtime | `required = max(activeCount, 1)` — an empty required set is never "closed" (inherited boundary, `orchestration.go:2397-2402`) | reactivate a seat |
| Directed mail addressed to a `retired` seat | runtime | roster-sensor-style warning ("addressed to retired seat") — mail still surfaces; sense, never hide | sender re-routes |
| Invalid seat id (traversal, unsafe chars) | usage | hard error via the existing `isPathSafeAgentId` guard — one guard, no new validator | — |
| Unreadable `.totem/orchestration/` dir (EACCES) during poll | runtime | `readSeatDirs` degrades to `[]` silently by its own shipped contract — therefore the poll's lifecycle filter derives from `resolveSelfAgents`' OUTPUT (whose degradation contracts are unchanged) and subtracts ONLY seats with a successfully-parsed `suspended`/`retired` marker; lifecycle can never shrink a denominator except via an explicit parsed marker (slice-1 leg finding) | fix dir perms; behavior meanwhile is no worse than shipped |

No silent-degradation rows. The corrupt-marker row is the ADR-115 induced-failure test.

### Invariants to lock in via tests

- Absent marker ⇒ `active`; a markerless tree's poll output is byte-identical to today's.
- Corrupt marker ⇒ warning fires AND the seat stays in the broadcast denominator AND its mail
  surfaces (three assertions, E4 pack contract — the degraded path never silently narrows).
- A `suspended` seat leaves the broadcast required-count; its **directed** mail still surfaces
  (obligation held, not discharged); own-broadcast/mark semantics unchanged.
- A `retired` seat's dirs, outbox, processed marks, and journals are untouched by `seat remove`.
- `host_agents` merge preserves every existing seat and every unknown passthrough key.
- `seat add` refuses an existing seat without `--reactivate`; `--reactivate` transitions only
  `suspended → active` (never resurrects `retired` — that needs a fresh ruling, hard error).
- The marker schema rejects any session-state vocabulary (`LIVE`/`IDLE`/`FAULTED`) — strict enum.
- `by` is never fabricated: unset env ⇒ field absent, and the written marker round-trips strict parse.
- The doctor identity check is `gateExempt` (sense-only, Tenet 9) and flags: outbox `from:` ≠
  owning dir seat; recent outbox writes under a `suspended`/`retired` marker (writing-while-
  excluded); `TOTEM_SELF_AGENT` naming a non-active seat. (Honest limit, stated in the check's
  output: a consistent fake — wrong dir + matching forged `from:`, the agy shape — is NOT
  detectable post-hoc; that is why full write-time binding is judged infeasible for v1 and the
  doctor tier is the chartered fallback.)
- Induced lifecycle tests run the built CLI against a temp copy of `totem-fixture-ts`:
  add → dirs + marker + (config where present) + poll visibility; suspend → denominator exclusion
  measured through `pollMail`; remove → `retired` + retention intact.
