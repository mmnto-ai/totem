## Lesson — Deleting a dead installer keeps the tests of the helper it shared

**Tags:** testing, refactoring
**Scope:** packages/cli/src/commands/**/*.ts, !**/*.test.*, !**/*.spec.*

When the unused Claude Code lint-gate installer was deleted, its test block was the only coverage of four behaviours of the shared settings-merge helper: a hooks object of the wrong shape, a config with no hooks, a deep merge beside a bare-string hook, and the skip when the entry is already present. Those four cases were ported onto the surviving write-shield path before the block was removed (mmnto-ai/totem#3006). Deleting a caller is the moment to ask which of its tests were really testing what it called.
