## Lesson — A freshness probe on the delegation path never throws

**Tags:** cli, re-exec, sensor, error-handling
**Scope:** packages/cli/src/reexec-local.ts

The workspace freshness read decorates a delegation; it must not be able to stop one. Its catch does not rethrow, not even under `TOTEM_DEBUG=1`: a file that vanishes between the directory read and the stat would otherwise crash a command the base code would have run (a falsification read found exactly that rethrow in the first build). On a failed read the banner drops the build instant, no stale line prints, one debug line names the failure, and the CLI delegates as before (mmnto-ai/totem#2998).
