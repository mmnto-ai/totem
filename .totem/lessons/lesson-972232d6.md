## Lesson — The MCP config loader turns jiti's module cache off

**Tags:** mcp, config, jiti
**Scope:** packages/mcp/src/context.ts

The MCP server loads the Totem config through jiti with `moduleCache: false`. With the cache on, jiti serves the config file from Node's module cache, so a re-read after an edit (a project-basics read while no context is cached, or a retry of the context init) returns the first load, not the file on disk (mmnto-ai/totem#3012).
