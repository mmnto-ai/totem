## Lesson — An untrusted Gemini folder never reads the reflex block

**Tags:** gemini-cli, workspace-trust, reflex-block, doctor
**Scope:** packages/cli/src/commands/init-templates.ts, packages/cli/src/commands/doctor.ts

In a folder Gemini CLI 0.61.0 does not trust, it loads neither the MCP servers nor the project `GEMINI.md`. An instruction placed in the managed reflex block cannot reach a Gemini seat in exactly that case, so the reflex item for absent Totem tools must not name workspace trust as its cause or point at the trust row. The signal for that case is the `Gemini Workspace Trust` row of `totem doctor`, run from a terminal; the reflex item serves the other ways the tools go missing. A drift test pins that the item mentions neither Gemini nor `totem doctor` (mmnto-ai/totem#2999).
